About

This is a personal-use file backup utility using rclone and Google Drive. It helps the account owner store copies of selected private files, check that uploads succeeded, and recover files when needed.

It is not a public file sharing or storage service. Only the Google account owner grants the application access to Google Drive.

See the privacy policy and terms of use for information about Google Drive access.

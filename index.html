About the application

Perevertysh Backup is a personal-use integration configured with the open-source rclone tool. Its purpose is to back up operational logs, monitoring snapshots, and recovery archives from a private VPS to a Google Drive account controlled by the same owner.

The application is not a public cloud-storage service. It does not provide access to trading accounts or execute trades. Google Drive authorization is used only for file backup, recovery, and integrity verification requested by the account owner.

Data handling

Files remain in the owner's control on their private server and Google Drive. OAuth credentials must not be published in this repository. The application does not use Google user data for advertising.

Privacy policy

Last updated: October 22, 2026.

Purpose and Google Drive access

This is a personal backup utility for the account owner. Google OAuth authorization enables the utility to access Google Drive files and folders within the permissions granted by the owner, including reading metadata, uploading backup files and verifying stored copies.

Data handling

Selected local files are uploaded to the owner's own Google Drive. Access credentials are stored privately in the owner's configured environment; no Google account passwords are requested by the utility. The application does not intentionally publish private files, sell user data, or use Google Drive data for advertising.

Retention and user control

The owner controls retention, can delete backups from Google Drive, and can revoke access in Google Account settings at any time. Revoking authorization stops future access, but does not automatically erase files already stored.

Limited use

Information obtained through Google APIs is used only to provide this authorized file backup functionality. It is not sold to advertisers or data brokers.

Questions

For questions, use the repository contact page. Never post access tokens or personal documents in public issues.

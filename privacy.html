Privacy policy

Last updated: October 22, 2026.

Purpose

This is a personal, non-commercial backup application used by the owner of the linked Google account. It connects to Google Drive through OAuth in order to upload backup archives and monitor their integrity.

Google account information and files

Through the Drive API, the application may access file names, identifiers, metadata, and file contents as permitted by the scopes granted by the owner. It creates and reads backup files, verifies uploaded content, and may list files to prevent duplicates and restore backups.

Storage and sharing

Backup files originate on a private VPS and are stored in the owner's Google Drive. OAuth credentials are intended to be retained only in access-controlled local configuration on the owner's devices or server. The application does not intentionally make backed-up files public, sell personal data, or use Google data for ads. Google processes files as the storage provider under its own terms.

Retention and deletion

The owner controls files and may delete backups directly from Google Drive and remove local backup copies. The owner may revoke OAuth access through Google Account security settings. Revocation prevents future authorized Drive API access but does not itself delete existing files.

Limited use

Google API data is used only for this user-authorized backup functionality. It is not transferred to advertising platforms or data brokers.

Contact

Questions about this personal application may be raised through the project's GitHub Issues. Do not post private data or credentials in public issues.
